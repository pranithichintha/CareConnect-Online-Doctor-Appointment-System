# CareConnect - Online Doctor Appointment Booking System

CareConnect is a web-based doctor appointment booking application.

## Features
- View doctors
- Book appointments
- View appointments
- Cancel appointments
- Admin appointment view

## Technologies Used
- HTML, CSS, JavaScript
- Python Flask
- SQLite
- AWS EC2
- Gunicorn and Nginx

## Project Deployment
Deployed on AWS EC2 using Gunicorn and Nginx.

## Run Locally
1. Open the backend folder.
2. Create and activate a Python virtual environment.
3. Install dependencies: pip install -r requirements.txt
4. Run the application: python app.py

## Disclaimer
Educational project. Do not use real patient information.
